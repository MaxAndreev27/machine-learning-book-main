# Support

This repository contains educational examples rather than a production service. Before asking for help:

1. Read the setup and run instructions in [README.md](README.md).
2. Activate the repository's `.venv`.
3. Run `python -m pip check`.
4. Reproduce the issue with the smallest relevant example.

For questions or reproducible bugs, open a GitHub issue using the appropriate template. Include your operating system, Python version, package installation method, command run, full traceback, and whether the problem affects the notebook, GridWorld, or CartPole example.

Do not post credentials, tokens, private data, or large generated outputs in issues.
