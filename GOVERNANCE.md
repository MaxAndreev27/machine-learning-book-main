# Governance

## Project scope

This repository is a focused educational companion for reinforcement-learning examples. Changes should support clarity, reproducibility, accessibility, and compatibility with the documented Python environment.

## Maintainers

The repository maintainers are the people listed in the GitHub repository settings and commit history. GitHub permissions determine who can merge changes, publish releases, or modify repository settings.

## Decision making

- Small documentation and bug fixes may be merged after normal review.
- Changes to public behavior, dependencies, or learning algorithms should include a clear rationale and validation.
- Breaking changes should be discussed in an issue or pull request before implementation.
- Maintainers may request changes, defer a proposal, or close work that is out of scope.

## Changes to this policy

Governance changes should be proposed through a pull request and reviewed like any other project-level change.
