# Code of Conduct

## Our standard

We want this project to be a welcoming place for learning and collaboration. Participants are expected to:

- be respectful and constructive;
- assume good intent while discussing technical disagreements;
- focus criticism on ideas, code, and behavior rather than people;
- welcome questions from beginners;
- give credit for contributions and sources;
- protect personal information and private reports.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, sexualized comments, and deliberate disruption of project spaces.

## Enforcement

Report conduct concerns privately through the security contact described in [SECURITY.md](SECURITY.md), or through the repository's private reporting features when available. Include enough context to investigate safely.

Maintainers may remove comments, close discussions, or restrict participation when behavior violates this code. Actions should be proportionate, documented, and applied consistently.

## Scope

This code applies to project issues, pull requests, discussions, code review, documentation, notebooks, and other project spaces.
